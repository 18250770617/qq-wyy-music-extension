# CloudMusic Edge

一个面向 Windows + Microsoft Edge 的轻量音乐控制扩展。它提供可自由停放、靠近网页左右边缘时自动吸附的悬浮球，并通过安全的本地桥接连接网易云音乐或 QQ 音乐官方能力。

## 目前能做什么

### 网易云音乐

- 调用网易云官方 `@music163/ncm-cli` 搜索歌曲和歌单。
- 点击可播歌曲播放；不可播、会员受限、数字专辑和试听歌曲也会保留在列表中，并用独立锁形徽标明确原因。
- 暂停、继续、停止、上一首、下一首、音量和播放状态。
- 使用官方配置向导和网易云 App 扫码登录。

### QQ 音乐

- 调用腾讯官方 QQ Music Skills API 搜索歌曲和歌单、读取歌单详情。
- 点击歌曲打开 QQ 音乐官方 H5 页面播放。
- API Key 用 Windows DPAPI 加密，只能由保存它的 Windows 用户解密。

QQ 的公开官方 API 当前不返回第三方音频播放流，因此 QQ 模式不伪装成插件内播放器，也不使用逆向接口绕过这一限制。

## 第一次安装

个人使用推荐直接双击 `CloudMusicEdge-Setup-v0.8.0.exe`：

1. 点击“安装 / 修复并打开 Edge”。程序会安装到 `%LOCALAPPDATA%\Programs\CloudMusicEdge`，注册当前用户的本地桥接，复制扩展目录并打开 `edge://extensions`；不需要管理员权限。
2. 在 Edge 扩展页打开“开发人员模式”，点击“加载解压缩的扩展”，粘贴已复制的目录并选中。浏览器要求这一步由用户本人确认，安装器不会用策略强装。
3. 需要网易云时，在安装器点击“安装 / 更新网易云依赖”，随后点击“配置并扫码登录”。
4. 固定工具栏上的 CloudMusic Edge 图标并打开它。

安装器没有代码签名，个人构建首次运行时 Windows SmartScreen 可能显示提示；请只使用自己从本仓库构建的文件并核对来源。开发源码流程仍可双击 `启动助手.cmd`，或直接运行 `安装.cmd`。

如果整个项目文件夹被移动，重新双击一次 `安装.cmd` 即可刷新连接路径。

## 启用网页悬浮球

1. 打开希望使用悬浮球的普通网页。
2. 点击 Edge 工具栏中的 CloudMusic Edge。
3. 点击“在当前网站启用悬浮球”，确认 Edge 的当前站点授权。
4. 页面右侧出现圆形音频悬浮球。它可停留在页面中间，拖到左右边缘附近时会自动吸附；单击展开快捷按钮，点击末端按钮打开完整播放器。

授权是按网站保存的。未授权网站不会注入脚本；扩展不会读取网页正文、表单、Cookie 或网络请求。Edge 内部页、扩展商店和部分受保护页面不允许扩展注入，这是浏览器的正常限制。

需要关闭时，在同一网站再次打开扩展，点击“关闭当前网站悬浮球”。

## 连接网易云音乐

1. 打开扩展，选择“网易云音乐”，点击“设置”。
2. 点击“安装/更新依赖”。助手会检查 Node.js 18+、安装官方 ncm-cli，并安装 mpv。
3. 点击“配置并登录”。按官方向导填写开放平台 App ID 和 Private Key，再用网易云 App 扫码。
4. 回到扩展点击右上角刷新按钮，看到“连接可用”后即可搜索播放。

API 凭证申请入口：<https://developer.music.163.com/st/developer/apply/account?type=INDIVIDUAL>。先完成个人开发者入驻审核，再到“应用管理”创建应用，最后把该应用的 App ID 和 Private Key 直接填入官方 `ncm-cli configure` 向导。会员身份不能替代开发者认证。

相关官方接口、签名与上线文档索引见 [`docs/netease-official-api.md`](docs/netease-official-api.md)。

本项目不会接触网易云 Private Key 或登录态，它们由 ncm-cli 自己管理。会员歌曲能否播放仍由账号权益和歌曲版权决定。

Windows 上通过 winget 安装的 mpv 有时不会自动加入 PATH；安装助手会补齐当前用户 PATH，桥接程序也会识别默认的 `C:\Program Files\MPV Player\mpv.exe`。若安装时 Edge 已经打开，请重启 Edge 后再检测。

`ncm-cli 0.1.7` 在 Windows 上的控制命令偶尔会先超时、随后才开始播放。0.8.0 仍由官方 CLI 完成鉴权、搜索、个人歌单读取、取流和歌单队列；暂停、继续、停止、音量、播放进度和实时频段连接 CLI 创建的 `ncm-mpv` 本地管道。插件会在媒体路径变化以及播放/切歌后用官方 `ncm-cli state` 核对真实曲目，避免不可播歌曲被 CLI 跳过后界面仍显示原请求名称。工具栏弹窗和网页悬浮窗统一经过后台路由：数据加载、播放控制和实时频段各使用独立的 Native Messaging 长连接，读取大歌单时不会再把频谱与控制请求堵在同一队列中，同时两处界面共享后台播放事务锁。扩展不会读取或接收播放 URL。

### 网页悬浮播放器

在普通网页中打开扩展，点击“在当前网站启用悬浮球”。44px 悬浮球可以自由停在网页中间，进入左右 64px 磁吸区后才贴边；开始拖动时会收起播放器。单击会展开上一首、播放/暂停、下一首快捷操作，再点击末端按钮可打开紧凑的双栏播放器。播放器优先显示在悬浮球上方，空间不足时自动改到下方；左栏是播放和音频视觉控件，右栏是可独立滚动的搜索、个人音乐与歌单歌曲列表。

点击歌单会先进入歌单详情，再由用户选择歌曲播放；详情、搜索分类和个人音乐会分别保留列表、分页与滚动位置。单曲或整张歌单正在启动时会显示加载态，并拦截重复播放点击。歌曲列表不会隐藏不可播项：完整播放、试听、当前端无版权、需要音乐会员、数字专辑和未知状态都会保留原顺序；不可播项以高对比状态徽标和侧边色条标明原因，点击只显示说明，不会发送播放命令。右上角调色盘可选择曜石、雾蓝、墨绿、暮色主题，并调整背景不透明度（32%–100%）、字体风格、文字大小，以及是否在网页底部显示频谱坞。底部频谱坞无整块背景，居中占约 62% 视口宽度，高度可在 72–180px 间调节；频谱从页面底边单向向上生长，上一首、播放/暂停、下一首按钮也没有容器底色。所有外观设置都保存在扩展本地存储中。

网易云播放期间，只要播放器面板或底部频谱坞可见，就会临时在 mpv 内启用固定的 10 频段分析器（31Hz–16kHz）。视觉映射同时使用绝对响度、相邻频段差值和相邻帧瞬态，并对差值做四次方增强；展开后的所有柱会减去当前最低柱，只为最低项保留一条细线，从而拉开峰谷。暂停或停止后，悬浮球、面板和页面底部的频谱柱都会归零。两者都关闭、暂停或切换 QQ 音乐后会移除分析器。当前版本选择只分析本扩展正在播放的音乐，不申请桌面录音权限、不监听其他应用或整台电脑的声音，也不读取播放 URL、上传或落盘；旧版 mpv 不支持时自动退回播放状态动画。

搜索结果按“平台 + 歌曲/歌单”分别缓存，切换分类后关键词、列表和滚动位置都会保留。网易云下的“我的音乐”可通过官方 ncm-cli 读取喜欢歌曲、自己创建的歌单和收藏的歌单，歌曲首批按 40 首加载，同一歌单的重复读取会合并；列表滚到距底部约 48px 时自动读取下一页，并只把新项目追加到下方，不再显示“加载更多”按钮，也不会跳回顶部。个人列表只保存在当前页面内存中，刷新后重新从官方账号读取。授权按网站保存，扩展不会读取网页正文；Edge 设置页、扩展页等内部页面不能注入。

### 插件特藏

“插件特藏”与“搜索”“我的音乐”并列。搜索结果、喜欢歌曲、创建/收藏歌单和歌单详情都带独立星标；点亮后只加入插件自己的本地列表，不会改变网易云红心、账号歌单或 QQ 收藏。“我的音乐 → 喜欢”中的“特藏已加载”会保存当前已加载的歌曲，不会为导入而继续读取账号的其余页面。

特藏保存在 `%LOCALAPPDATA%\CloudMusicEdge\plugin-collection.json`。除星标单曲和收藏歌单外，“自建歌单”可以创建、重命名和删除插件自己的场景歌单；搜索、喜欢列表和歌单详情中的歌曲可通过 `＋` 加入，进入后可逐首播放或移除。它允许混合网易云与 QQ 歌曲，因此不伪装提供跨平台连续播放：网易云仍由官方 CLI 播放，QQ 仍打开官方 H5。最多保存 2000 个星标、100 个自建歌单，每个自建歌单最多 500 首且自动去重；删除星标不会连带删除歌单快照。文件只含平台、官方资源 ID、标题/作者、可播说明和时间，不含账号凭据、Cookie 或音频流地址。

## 连接 QQ 音乐

1. 打开扩展，选择“QQ 音乐”，点击“设置”。
2. 点击“打开官方 Key 页面”，登录 QQ 音乐并获取以 `qmk-` 开头的 Key。
3. 把 Key 粘贴到设置框，点击“安全保存并检测”。
4. 搜索歌曲或歌单；点击歌曲会打开 QQ 音乐官方播放页。

官方 Key 页面：<https://y.qq.com/n/ryqq_v2/qqmusic_skills>

## 检测、更新和卸载

- `启动助手.cmd`：图形化集中入口，可安装、检测、复制扩展路径、打开授权页面和重新打包。
- `检测连接.cmd`：检查 Host 注册路径、Node.js、ncm-cli、mpv 和两种 Provider 的配置状态。
- 网易云“安装/更新依赖”：运行 `npm install -g @music163/ncm-cli@latest`，由用户主动确认更新。
- 再次运行 `安装.cmd`：重新构建 Host 并修复移动后的路径。
- `卸载.cmd`：删除 Edge Native Messaging 注册，不删除扩展和用户配置。
- 完全清除 QQ Key：卸载后手动删除 `%LOCALAPPDATA%\CloudMusicEdge`。

## 复制到另一台电脑

普通无账号数据安装包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Package.ps1
```

桌面会同时生成 `CloudMusicEdge-v0.8.0.zip` 和 `CloudMusicEdge-Setup-v0.8.0.exe`。另一台电脑只需复制并运行 EXE，再手动加载一次扩展。

若要把“插件特藏”一起带走，运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Package.ps1 -IncludeCollection
```

会额外生成 `CloudMusicEdge-Personal-Setup-v0.8.0.exe`。它只内嵌当前星标特藏与插件自建歌单，在目标电脑还没有特藏文件时恢复；不会覆盖目标电脑已有特藏。两种包都不包含 QQ Key、网易云 Private Key、登录态、账号歌单缓存、外观设置或播放器状态，因此新电脑仍需分别完成账号授权。

## 安全设计

- 扩展和本机程序之间使用 Edge Native Messaging，不监听 localhost 端口。
- Host 只允许固定扩展 ID 调用，并拒绝所有未列入白名单的动作。
- 网易云关键词以独立进程参数传递，不拼接进 shell 命令。
- QQ 请求只发往 `https://a.y.qq.com`，播放入口只允许 QQ 官方 HTTPS 域名。
- QQ Key 不会回显给扩展、不写入日志、不放进环境变量或命令行。
- 插件特藏由 Host 白名单校验、数量限制、命名互斥和原子写入；个人迁移包拒绝非白名单字段和疑似凭据文件。
- 扩展没有 Cookie、webRequest 或默认全站访问权限。

## 开发验证

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Test.ps1
```

测试覆盖 Manifest 权限、JavaScript 语法、C# 构建、Native Messaging 帧和动作白名单。真实账号登录、会员版权以及第三方官方服务可用性必须由用户在自己的账号环境中人工验证。

只读核对插件状态与官方 CLI 状态可运行 `node .\tests\native-live-identity.js`。它不会启动播放；若当前正在播放，也只比较曲名、状态和队列位置，不改变播放。

已完成网易云真实账号端到端验证时，还可运行 `node .\tests\native-live-netease.js`。它会搜索并播放一个歌单，严格检查播放、暂停、继续、下一首和状态，随后自动停止音乐。

个人音乐库可运行 `node .\tests\native-live-library.js` 做只读验证。它仅通过官方 CLI 读取少量创建歌单、收藏歌单和喜欢歌曲，不会更改账号内容或播放状态。

播放网易云歌曲时可运行 `node .\tests\native-live-visualizer.js` 验证 10 个频段值。脚本只临时添加固定 mpv 分析滤镜，验证后立即移除，不会保存音频。
