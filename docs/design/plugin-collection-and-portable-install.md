# 插件特藏与个人便携安装设计

## 目标

本版本面向项目所有者个人使用：在一台新 Windows 电脑上只需运行一个安装程序，再在 Edge 中手动“加载解压缩的扩展”一次。插件特藏提供独立于网易云、QQ 账号的本地收藏，不向任一平台写入收藏或歌单。

## 安全边界

- 网易云只调用官方 `@music163/ncm-cli`；QQ 只调用官方 Skills API 或打开官方 H5。
- 安装程序不修改 Edge 策略、不自动打开开发者模式、不静默强装扩展。
- 账号登录、App Private Key 和 QQ API Key 必须在目标电脑重新授权。
- 迁移包只允许携带 `plugin-collection.json`；不得携带 `qq.key`、ncm-cli 配置、Cookie、登录态、播放器状态、PEM/PFX 或播放 URL。
- 插件特藏只保存资源定位与展示所需的最小非敏感字段，不保存官方接口的完整原始响应。

## 数据模型

文件位置为 `%LOCALAPPDATA%\CloudMusicEdge\plugin-collection.json`。V2 结构包含 `version: 2`、星标资源 `items` 和插件自建歌单 `playlists`；V1 文件会在首次写入时无损升级。星标项包含稳定 `key`、平台、歌曲/歌单类型、官方资源 ID、标题、摘要、可播放状态、原因和本地添加时间。

每个插件歌单包含本地 GUID、名称、创建/更新时间及歌曲快照。歌单名称为 1–40 字，同名不区分大小写并拒绝重复；最多 100 个歌单，每个最多 500 首，按歌曲稳定 key 去重。歌曲快照沿用星标资源的字段白名单，因此从星标移除歌曲不会破坏已创建的场景歌单。

Host 负责生成稳定 key、字段白名单、长度与格式验证。星标最多保存 2000 项；单次导入最多 100 项；列表每页最多 100 项。写入时使用命名互斥锁及同目录临时文件替换，避免多个 Native Messaging 进程并发写坏文件。损坏文件保留为 `.corrupt-*` 后重新建立空库。

## UI 与行为

悬浮播放器右栏提供“搜索 / 我的音乐 / 插件特藏”三个并列入口。搜索结果、喜欢歌曲、创建/收藏歌单以及歌单详情中的项目均可通过星标加入或移出特藏。特藏按“歌曲 / 歌单”分页并自动加载；点击项目沿用现有官方播放或官方 H5 流程。

插件特藏内增加“自建歌单”分类，可新建、改名、删除歌单。歌曲行提供“加入插件歌单”，自建歌单详情可分页查看、逐首播放并移除歌曲。歌单允许混合网易云与 QQ 项目；播放某首时切换到对应官方 Provider。由于 QQ 官方接口不提供第三方音频流，本版本不提供会误导用户的混合歌单连续播放按钮。

“收藏当前已加载的喜欢歌曲”仅把当前页面已经读取到的条目分批写入本地特藏，不会继续抓取未加载页面，也不会改变网易云红心列表。

## 安装与迁移

`CloudMusicEdge-Setup-v<version>.exe` 内嵌运行所需的扩展、预编译 Host 和网易云依赖脚本。安装到 `%LOCALAPPDATA%\Programs\CloudMusicEdge`，在 HKCU 注册 Native Messaging Host，然后复制扩展目录并打开 `edge://extensions` 供用户手动加载。

安装/升级默认保留现有特藏。构建个人迁移安装包时可显式选择嵌入特藏副本；目标电脑仅在本地尚无特藏文件时恢复该副本，避免覆盖已有数据。

## 非目标

- 不发布到扩展商店、不进行企业策略部署。
- 不绕过版权、会员、地区或数字专辑限制。
- 不把不同来源歌曲拼成绕过官方播放器能力的私有音频队列。
- 不监听整台电脑的系统声音。
