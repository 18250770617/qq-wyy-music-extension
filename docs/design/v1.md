# 设计方案：V1

## 推荐方案

使用 Native Messaging 替代 localhost Web 服务，降低端口暴露、跨站请求和固定 Token 配对风险。Host 编译为小型 .NET Framework EXE，以适配大多数 Windows 10/11 电脑且无需随包携带 Node 运行时。

## 接口

```text
system.ping / system.doctor
settings.get / settings.setQqKey / settings.clearQqKey
netease.search / netease.play / netease.playPlaylist / netease.playlistTracks / netease.library
netease.queueAdd / netease.control / netease.visualizer / netease.launchSetup
qq.search / qq.playlistDetail / qq.test / qq.openKeyPage
```

所有 ID、关键词、页码和音量在 Host 再次校验。网易云返回的歌曲全部保留在列表中，并按官方字段归类为完整播放、试听、受限或未知；只有明确可播/试听且具有可识别 encrypted/original ID 的项目允许发送播放动作。受限项保留可聚焦/点击能力以展示原因，但事件处理器会在任何 Native Messaging 调用前拦截播放。

`netease.visualizer` 只接受 `start/read/stop` 三种模式。Host 内置固定的 31Hz–16kHz 十频段 mpv/FFmpeg 滤镜图，不接受前端传入滤镜字符串；返回值只含经过 `-90..0dB` 限幅的十个 RMS 数值。

## 成功路径

1. 安装脚本编译 Host、写入仅当前用户的 Native Messaging 注册表项。
2. Edge 根据 manifest 固定公钥生成固定扩展 ID，与 Host allowed_origins 匹配。
3. Popup 请求诊断并根据用户选择路由到对应 Provider。
4. Service Worker 将数据、播控和频段动作路由到三条独立 Native Messaging 长连接，Provider 返回结构化结果或可行动错误。

网页悬浮球通过 `optional_host_permissions` 按来源授权。已授权站点列表保存在扩展本地存储，并注册持久化动态 content script；当前页面授权后立即注入。组件封装在 Shadow DOM 中，不检查宿主页面内容。悬浮球可自由停放，仅在距离左右边缘 64px 内自动吸附。播放器采用紧凑双栏布局，搜索、个人音乐和歌单详情使用独立滚动视口；可选的页面底部频谱坞复用同一份播放状态和十频段数据，使用无整块背景的透明布局，居中覆盖约 62% 视口宽度，高度由用户在外观面板中调节，频谱柱贴底并仅向上生长，操作按钮无底板。

播放器身份以官方 `ncm-cli state` 为准。常规 1.5 秒轮询直接通过 mpv IPC 读取暂停、进度、时长、媒体路径和播放列表位置；仅在首次、路径/位置变化或 10 秒兜底时调用官方状态命令核对曲名与队列，避免维护一份会因试听/不可播跳过而错位的影子队列。歌单/个人库请求进入数据通道，播控与状态进入控制通道，80ms 频段读取进入频段通道；大列表还会省略已成功解析 JSON 的重复原始 stdout。

## 失败路径

- Host/CLI 缺失：显示安装按钮和检测详情。
- 授权缺失：打开可见终端运行官方配置/登录流程。
- QQ Key 无效：不重试轰炸，显示 HTTP/官方错误并允许替换 Key。
- CLI 超时：终止子进程，避免悬挂 Host。

## 安全

- Native Host 限定固定扩展 origin。
- 未获得站点权限时不注入悬浮 UI；权限范围按单个 origin 保存。
- Host 不提供任意命令动作；控制动作采用枚举映射。
- 音频分析只处理官方 CLI 创建的 `ncm-mpv` 播放链路；不申请 `desktopCapture`/`tabCapture`，不监听系统或其他应用音频。
- QQ Key 经 DPAPI CurrentUser 加密，日志和响应仅返回 `configured: true/false`。
- URL 只允许 `https://y.qq.com`、`https://i2.y.qq.com` 和申请 Key 的官方地址。
- 安装和更新均由用户主动点击，绝不静默提升权限。

## 测试计划

- 单元/静态：manifest、消息契约、危险权限、密钥明文、允许域名、输入边界。
- 构建：C# Host 编译，安装清单 JSON 校验，zip 内容审计。
- 冒烟：向 Host 写入 Native Messaging 帧，验证 ping、未知动作拒绝、无 Key/无 CLI 错误。
- 人工：Edge 加载扩展；真实网易云/QQ 授权与音乐播放需要用户账号完成。

## Review 记录

设计自审结论：V1 不引入本地服务器和第三方播放器框架；QQ 不使用逆向播放 URL。牺牲了 QQ 插件内直接播放，但符合当前官方能力、安全和可维护性目标。
