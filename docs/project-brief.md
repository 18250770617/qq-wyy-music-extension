# 项目需求摘要：CloudMusic Edge

## 1. 项目目标

制作一个简洁的 Edge 扩展，让个人用户选择网易云音乐或 QQ 音乐连接方式，完成连接检测、歌曲/歌单搜索和可用的播放入口；整个项目可压缩为一个小文件夹，在另一台 Windows 电脑解压后重新安装。

## 2. 目标用户

- 主要用户：拥有网易云音乐或 QQ 音乐账号的 Windows/Edge 个人用户。
- 管理员角色：无；所有配置属于当前 Windows 用户。

## 3. V1 范围

### 必须包含

- Edge Manifest V3 扩展和清晰的双平台选择界面。
- 按站点授权的可拖动悬浮球，可停留在页面中间，靠近左右边缘时自动吸附，点击展开播控或搜索卡片。
- 本地桥接的安装、卸载、检测和重新定位。
- 网易云官方 ncm-cli 的安装检测、配置/登录入口、搜索、歌单取曲、播放与基础播控。
- QQ 官方 Skills API Key 的安全保存、连接检测、歌曲/歌单搜索与官方页面播放入口。
- 中文使用说明、故障诊断、安全说明和可移植压缩包。

### 可以后置

- 歌词、桌面通知、收藏编辑、音质选择、自动更新程序。
- QQ 音乐插件内音频流播放（公开官方 API 当前不提供播放流）。

### 明确不做

- 抓取网页登录 Cookie、逆向 weapi/eapi、绕过付费或地域版权。
- 将任何 API Key、私钥或登录态放进项目目录或压缩包。
- 自动操作真实账号的收藏、歌单修改等写操作。

## 4. 核心流程

### 首次安装

1. 解压文件夹并双击 `安装.cmd`。
2. 在 Edge 扩展页加载 `extension` 文件夹。
3. 打开扩展，根据诊断结果配置网易云或 QQ 音乐。

### 网易云播放

1. 安装并配置官方 ncm-cli 与 mpv，扫码登录。
2. 在扩展中搜索歌曲或歌单。
3. 扩展通过 Native Messaging 调用 ncm-cli 播放并提供暂停、继续、上下首和音量控制。

### QQ 音乐使用

1. 从 QQ 音乐官方页面获取 API Key，在扩展中保存。
2. 搜索歌曲或歌单。
3. 选择歌曲后打开 QQ 音乐官方 H5 页面/客户端完成播放。

## 5. 数据与集成

- 配置：`%LOCALAPPDATA%\CloudMusicEdge`。
- QQ Key：DPAPI CurrentUser 加密文件。
- 网易云凭据：由官方 ncm-cli 自身管理，本项目不读取。
- 第三方集成：Microsoft Edge Native Messaging、网易云 ncm-cli、mpv、QQ Music Skills API。

## 6. 权限

- 仅当前 Windows 用户可注册和使用本地桥接。
- 扩展基础权限为 `nativeMessaging`、`storage`、`scripting` 和 `activeTab`；网页注入使用用户主动授予的可选站点权限。
- 本地桥接只接受固定扩展 ID，并仅执行白名单动作。

## 7. 术语与命名

### Provider

- 定义：网易云或 QQ 音乐的一套独立连接适配。
- 避免混用：不是账号，也不是播放设备。

### 连接

- 定义：本地依赖已安装、授权有效且能调用官方能力。
- 说明：QQ 的连接不代表允许取得原始音频流。

## 8. 非功能需求

- 安全：不抓 Cookie；密钥 DPAPI 加密；无监听端口；命令白名单与输入校验。
- 部署：Windows 10/11、Edge MV3、每台电脑解压后运行一次安装程序。
- 可靠性：命令超时、错误回传、环境诊断、路径移动后可重新注册。
- 合规：仅使用官方接口和官方播放页面，不绕过会员/版权限制。

## 9. 风险与未知项

- ncm-cli 的远端命令树可能随版本变化；诊断会显示版本，更新由用户主动执行。
- QQ 官方 Skills API 目前只返回 H5 链接，不支持扩展内完整播控。
- Edge 不允许扩展自行完成“加载已解压扩展”，该步骤必须由用户在扩展管理页确认。
