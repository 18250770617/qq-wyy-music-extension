# 需求文档：V1 双平台连接与播放

## 目标与使用者

个人用户可以从 Edge 扩展选择网易云或 QQ 音乐，看到明确的连接状态，按引导完成安装授权，并搜索歌曲/歌单。

## 功能需求

### 安装与诊断

- 输入：当前文件夹位置和本机环境。
- 输出：Host 注册、依赖状态、修复建议。
- 规则：项目移动后重新运行安装即可刷新绝对路径；不得请求管理员权限。
- 提供便携式图形助手，将首次安装、扩展目录复制、平台配置、检测和打包集中展示。

### 网页悬浮球

- 用户在扩展弹窗中按当前站点授权后，页面显示悬浮球；未授权网站不注入。
- 悬浮球可拖动并自由停放，松手时仅在靠近左右边缘处吸附；点击展开上一首、暂停、继续、下一首和搜索按钮。
- 搜索按钮展开紧凑卡片，可切换 Provider、搜索并选择结果。
- 悬浮 UI 使用 Shadow DOM 隔离，不读取网页正文、表单、Cookie 或请求。

### 网易云

- 检测 Node、ncm-cli、mpv、ncm-cli 登录状态。
- 支持歌曲/歌单搜索、点击歌曲播放、歌单顺序入队、暂停、继续、上下首、状态与音量。
- 不可播放或无版权歌曲不得强行播放。

### QQ 音乐

- API Key 可保存、替换和清除，界面永不回显完整 Key。
- 支持官方歌曲/歌单搜索和歌单详情。
- 点击歌曲只打开腾讯返回的官方 H5 URL，不声称插件内播放。

## 边界情况

- Host 未安装、依赖缺失、未登录、Key 无效、网络失败、请求超时均展示可行动的错误。
- 空关键词不请求；关键词限制为 100 字符并拒绝控制字符。
- ncm-cli 输出格式变化时保留原始文本供诊断，不执行无法确认 ID 的播放。

## 验收标准

- [ ] `安装.cmd` 可构建并为当前用户注册 Host。
- [ ] 扩展 manifest 可被 Edge MV3 加载，且扩展 ID 稳定。
- [ ] `检测连接.cmd` 能识别当前 Host、Node、ncm-cli、mpv 状态。
- [ ] 扩展能选择两种 Provider，且未配置状态有清晰引导。
- [ ] 未授权网站不注入；授权后悬浮球可吸附、展开并发起搜索或播控。
- [ ] QQ Key 不以明文落盘，QQ 搜索只走官方域名。
- [ ] 网易云用户输入不会被当作 shell 命令执行。
- [ ] 可生成不包含用户凭据的 zip 包。
